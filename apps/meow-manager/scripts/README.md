Meow Manager asset and verification scripts, maintained by Codex for the APPS character-animation stage. prepare-frames.ts crops the current original2D art with FFmpeg; verify-frames.ts checks image custody and dimensions; review-frame-recording.py measures actual recorded pixel changes. The older export-character.ts/verify-character.ts/Blender pipeline reproduces the rejected3D rig as historical evidence. These scripts process local project data; artwork generation used the built-in tool and its prompts are separately recorded.
