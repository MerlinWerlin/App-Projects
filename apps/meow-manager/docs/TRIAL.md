# First-use trial

The initial build should answer one practical question: does a little cat make it easier to turn a messy day into the next useful step? Jared and his partner can start with their real day after trying the labelled example. No sign-up is needed. Browser data is separate from phone data.

1. Tap **Try an example day** from an empty home. Check the cat, spacing, task cards and navigation. The example stays separate from real tasks.
2. Add `Buy groceries today; book the dentist tomorrow at 3pm; finish my assignment`. Check and edit the proposals before saving. Change one time and choose whether it is fixed.
3. Open the assignment, make it smaller, complete a checklist step and start/pause a short focus session. Close it without completing the whole task.
4. Complete a task, reload the app and confirm the task and checklist state were retained. Add one daily ritual.
5. Open **Ask Meow**, request a day plan and try saying the day feels like too much. Check whether the responses are useful at the capabilities this build actually has.
6. Change the cat's name/personality, switch English/Japanese, and check whether the wording and character feel right.
7. Share a backup, then paste that same JSON into Restore. Confirm it reproduces the tasks and preferences. An invalid backup should leave current data alone.

On a real native phone build, separately verify a reminder two minutes ahead while the app is backgrounded; edit/cancel/complete a reminded task and check that the old notification does not arrive. Test notification denial, a notification tap, calendar read permission, a fixed-time clash, creating/canceling a calendar event and optional speech. Android's editor dismissal must not claim a saved event. These are pending device checks, not steps already passed in the browser.

Useful feedback is concrete: what you wanted the cat to do, what it actually did, where it felt confusing, and whether you would come back tomorrow. Japan is a proposed audience; fluent-user testing is needed before treating this as market-ready Japanese copy.
