# What to try (Expo Go)

Open Expo Go → Projects → Rowlight → preview (links in `ops/PREVIEW.md`). Ideal tester: someone mid-project.

1. Projects → **Try a sample amigurumi**. Tap + a few times: the "Now" card follows the pattern.
2. Open the pattern (tap the "Now" card): tap any round to jump; switch US/UK at the top.
3. Add a counter → "Stripe rows", repeat every 4, "Add 1 to Repeats" (make a Repeats counter first).
4. Add a reminder: "Change colour" on row 3 then every 2.
5. Add a PDF or a screenshot of a real pattern; drag the yellow ruler, tap + and watch it move a line.
6. Tools → Amigurumi ball → "Make it a project". Tools → Increase evenly, US ⇄ UK, Gauge, How much yarn.
7. Settings: switch to UK terms, turn on "Say the count out loud", try left-handed.
8. Settings → Export a backup, then Restore it (Merge).
9. Stash and Pricing: tap Get Plus → Unlock (free in test builds).
