# Market notes (24 Oct 2026 research, sources in the research report)

Competitor complaints we design against: bought patterns locked in-app; backup restore sold separately;
annotation/watch behind paywalls; subscriptions $18–30/yr; AI pattern apps at ~A$9/week; lost row counts after
updates; login lockouts; crashes with big libraries; Android lagging iOS; tracking SDKs.

Features users value most: several linked counters, any-PDF import with a line highlighter, keep-awake,
voice/read-aloud counting, row reminders, stash, US/UK terms, amigurumi maths, timer, dark/left-hand mode.

Size signals: r/crochet ~2.0M (+7%/yr), r/CrochetHelp ~152K (+41%/yr), Ravelry ~9M registered, crochet ~15B
TikTok views; 18–34s ~29% of yarn-craft demand. Name checks: avoid Hooked, Hooklings, Stitch Keeper, Looply,
YarnTally, RoundsKeeper; "Crochet Companion" is generic and used. Rowlight/Roundsy had no exact conflicts.
