# Template library guide

Templates live in `src/core/templateArt/*.ts` as SVG path data on a 400×400 viewBox and are registered in `src/core/templates.ts`.

- `paths`: main outlines (stroke `strokeWidth`, default 4). `detail`: fine lines (veins, hatching, fur, ornament) drawn at `detailWidth` (default 2).
- `level`: beginner (few bold shapes, kids and first-timers) · intermediate (internal detail) · advanced (intricate, hundreds of strokes, adult hobby art).
- `tags`: style (botanical, vintage, gothic, whimsical, ornamental, geometric, realistic, stylized, cute) and occasion (birthday, christmas, wedding, love, thanks, baby, halloween, easter, gift).
- All art is original, authored in this repo (procedural geometry or hand-placed curves). Never copy or trace existing artwork, logos, characters or trademarked designs. Lettering may be built from open-licence (OFL/GUST) font outlines.
- Budget: ≤ 30 000 characters of path data per template, ≤ 300 path strings, 1-decimal coordinates.
- Check by eye: `node scripts/export-templates.ts && python3 scripts/preview-templates.py <out> [id-prefix]` renders PNGs and contact sheets.
- Overlapping shapes: `src/core/templateArt/occlude.ts` (`stack`, `union`, `clip`) hides the part of an outline behind a closed shape, so a head in front of a body draws as one clean drawing. Avoid shapes whose edges coincide exactly (the hidden test is ambiguous on a shared edge).
- Cute & chibi (`cute.ts`, category `cute`): original kawaii-style pieces of our own design. Never draw or evoke an existing character, mascot, brand figure or franchise.
- fb-1022 (22 Oct 2026) genre sets, all original: Heroes (`heroes.ts`, `hero-`), Game world (`game.ts`, `game-`, pixel pieces via a grid-to-outline helper), Movie night (`movies.ts`, `movie-`), Fairy tales (`fairytales.ts`, `fairy-`), Kids (`kids.ts`, `kids-`). Each has a test with a banned franchise-word list; never draw or name an existing character, costume, emblem or logo.
- fb-1022b (22 Oct 2026 evening): new **Sea life** category (`sealife.ts`, `sea-`; whale, nautilus, koi and fish moved there), kawaii batches in the Cute shelf (`kawaiiFood.ts`, `kawaiiFriends.ts`, `kawaii-`), Movie night and Fairy tales grown to 40+, and the recurring original cast in `docs/CAST.md`. Name translations for new batches live in `src/i18n/packs/<batch>.ts` (merged by `src/i18n/catalogs.ts`), not in the big locale files. Guards: `src/core/templateSubjects.ts` (curated subjects per category) and `src/core/templateDuplicates.ts` (near-duplicate shapes). Size and library target: `docs/TEMPLATE_BUDGET.md`.
- **Baked sets (T117, 22 Oct 2026).** Sets drawn with generators (occlude.ts, helper geometry) are listed in `src/core/templateArt/baked/sets.ts` and baked into finished path strings by `node scripts/bake-templates.ts`; `src/core/templates.ts` imports only `./templateArt/baked/<set>.ts` for them, so the app never runs generation code (catalogue import ≈ 13 s → well under 1 s in Node). After changing a generator or adding a batch: add it to `sets.ts`, run the bake script, import the baked file. Guards: `baked/baked.test.ts` (baked == generated) and `templateLoad.test.ts` (import < 1 s, no runtime import of occlude.ts or a generator).
