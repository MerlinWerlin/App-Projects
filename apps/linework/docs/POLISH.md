## How this repo implements it (run 12 decision)

- **No new dependencies.** `react-native-reanimated`, `expo-blur` and `expo-linear-gradient` are not in `package.json`, and the npm registry is unreachable from the build runs, so adding them could not be installed, compiled or locked here; a reanimated install also needs the worklets Babel plugin. Breaking the trial on the eve of the owner's final test is the worst outcome, so the polish uses what already ships: React Native's `Animated` with `useNativeDriver: true` (transform/opacity animated on the UI thread), `AccessibilityInfo.isReduceMotionEnabled` for Reduce Motion (`useReduceMotion` in `src/theme/motion.ts`), `react-native-svg` gradients for the sheen and grain, and the existing dark glass fill (no blur) on the camera. "FadeInDown"/"LinearTransition" become an `Animated` fade + 8 pt rise per item and `LayoutAnimation` on add/remove.
- Motion tokens live in `src/core/motion.ts` (pure, tested) and are re-exported with the React helpers from `src/theme/motion.ts`.
- Nothing in the outline engine or `src/core` logic changes; only new pure helpers (stagger delay, slider detents, focus-mode idle timer) with tests.
- Not tested on a real device; the owner's re-test is the device check.
