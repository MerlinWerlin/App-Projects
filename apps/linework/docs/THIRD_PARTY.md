# Third-party material

## OpenCV LBP frontal face cascade
`src/core/faceCascade.ts` is generated (scripts/gen-face-cascade.py) from `lbpcascade_frontalface_opencv.xml`, a trained data file from the OpenCV project (https://github.com/opencv/opencv/tree/master/data/lbpcascades), as redistributed with scikit-image's sample data.

## Fonts used for lettering templates
Lettering template outlines (scripts/templategen/ornament.py) are derived from Lora, Young Serif, Gloock and Poppins (SIL Open Font License 1.1) and TeX Gyre Chorus (GUST Font License). Only letter shapes are used; the fonts themselves are not bundled.


## Fonts used for the Letters templates (owner 24 Oct 2026)
The one-character templates in `src/core/templateArt/letters/` (ids `char-<style>-<char>`) are generated by
`scripts/gen-letters.py` from the glyph outlines of these fonts, taken from the google/fonts repository
(https://github.com/google/fonts, paths `ofl/<family>/` and `apache/<family>/`). Only the outlines become line art
(stroked, not filled; pixel style rebuilt from its grid cells); the font files are not shipped in the app and no font
name is used as a template or style name. Both licences allow this use; each licence text is kept in `docs/licences/`.
The app's About screen should credit: "Letter outlines from open-licence fonts (SIL OFL 1.1 / Apache 2.0); see the licence list."
