## F1 Crash fix (T47)
Hermes (Expo Go and release builds) has no Intl.PluralRules, so `new Intl.PluralRules(...)` in src/i18n/core.ts pluralCategory threw "TypeError: undefined cannot be used as a constructor", a Render Error that broke the Templates screen (every template) and picking a photo to trace. The PC fix replaces the Intl.PluralRules cache with: type PluralRule = 'zero'|'one'|'two'|'few'|'many'|'other'; a fallbackRule(locale) CLDR table (ja/ko/zh → always other; fr/pt/hi → one when floor(|n|) <= 1; ar → zero 0, one 1, two 2, few n%100 in 3..10, many n%100 in 11..99, else other, non-integers other; default en/de/es/it/others → one only when n === 1); pluralCategory reads globalThis.Intl?.PluralRules and uses it only if it is a constructor (try/catch → fallback), caching a selector function per locale. Tests run pluralCategory with Intl.PluralRules deleted (en 1→one, 2→other; ar 0→zero, 3→few, 11→many; fr 0→one; ja 5→other), and a ui-check / test rule says no code outside guarded helpers calls `new Intl.X(` for APIs Hermes lacks (PluralRules, RelativeTimeFormat, ListFormat, Segmenter, DisplayNames). Audit every Intl use in the app for the same problem.

## F3 Better outlines (T49)
The owner says the outline "works but is not quite capturing the image well enough". Upgrade the pure-JS outline engine (Expo Go compatible, still fast on a phone: downscale to ~1024 px long edge, run off the UI thread or in chunks with progress):
(a) a proper Canny pipeline — grayscale with local contrast normalisation (CLAHE-style), Gaussian/bilateral smoothing, Sobel gradients, non-maximum suppression, hysteresis with automatic thresholds from the gradient histogram (median/Otsu), then thinning;
(b) a "Sketch" style using XDoG (difference of Gaussians with soft threshold) which usually reads better for tracing faces, animals and soft subjects, alongside a clean "Line art" (Canny) style and a "Bold" style (dilated lines);
(c) speck removal (drop connected components below a size threshold) and gap bridging for small breaks;
(d) Detail and Line weight sliders with live preview and sensible defaults per style;
(e) an "Invert / dark paper" toggle.
Build a small fixture set of original test images (generated shapes, a synthetic portrait-like gradient image, text) with golden-metric tests (edge recall/precision against known edges, speck count, runtime budget) so changes are measured, and record before/after metrics in RUNLOG. Note in docs/PLAN.md that true subject cut-out / background removal needs a native module (iOS Vision subject lifting) in a development or TestFlight build, and add it as a later NATIVE task behind an adapter.
