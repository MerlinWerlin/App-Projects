Native theme clocks preserve the artwork. A number-free image can supply `liveFrame.clockStyle` (`analog`, `digital`, `stacked`) and optional six-digit hex `ink`; validated metadata survives pack parsing, source-to-composed geometry and the native record. Legacy options keep their previous analog/time layout. Analog draws only hands over a supplied dial; digital follows the device time format; stacked intentionally displays two rows of24-hour hours/minutes. All use real timeline dates and retain the existing per-minute schedule.

`prepare-themed-clocks.mjs` prepares105 additive native art-clock editions from the reviewed collection. Alpine Starlight and Rainlight have separately edited backgrounds with painted values removed; other editions reuse existing decorative art with a live digital clock in an automatically selected low-detail area. These are new clock editions, not claims that every original painted timepiece is converted. Individual artistic/layout review remains required. No original artwork or icon design is replaced.

`themed-clock-profiles.json` records source hashes, style, frame and production-computed composed specs. CI-only downscaled fixtures let the native harness render complete compositions in three sizes, both Fit/Fill layouts and four times. It uses the actual native value view and production-computed geometry but does not install the WidgetKit extension or test App Group delivery, timeline reloads on a phone, or TestFlight. Original sources stay outside the app bundle. Nothing is uploaded to customers by these scripts. Earlier flat icon exports remain technical prototypes and are not final themed designs.

The manual and automatic save paths call `setClockArt` / `composeClockArtPiece` for these clock editions, preserving the background instead of passing it through background-keying/feathering. `ClockArtRenderer.swift` is shared by the bridge and review harness: original art fits whole over blurred extensions only where aspect ratios differ. Older bridges report not-built instead of silently saving a stripped version. Existing non-clock art retains its established blending behavior. Native clock captures therefore exercise the same artwork renderer as the save path, while full bridge/App Group installation remains a separate check.
