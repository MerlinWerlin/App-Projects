PREMIUM POLISH (owner request 13 Oct 2026, one-time import; skip the import if ops/backlog.json already has tasks tagged "polish-1013"): the owner wants the app to feel premium before his final test tonight. Copy this whole section into docs/POLISH.md, add backlog tasks tagged "polish-1013" that outrank everything except trial blockers and open owner-comment / owner-feedback tasks (the 12 Oct theme-redesign feedback still comes first where they overlap — polish the new theme tab, not the old one), and do as many as fit each run until they are done.

Shared rules: (1) src/theme/motion.ts with durations fast 120 / base 200 / slow 320 ms, one spring preset (damping ~18, stiffness ~220) and an ease-out curve; every animation reads it; Reduce Motion (reanimated useReducedMotion) swaps movement for a short fade or nothing. (2) Smooth navigation: native slide for stack pushes, sheets spring up over a dimmed backdrop, tab switches cross-fade, nothing over ~350 ms, never block input. (3) A shared PressableScale for buttons/cards: scale 0.97 with the spring, light haptic on primary actions, selection haptic on toggles/pickers, success haptic on completions, all following the Haptics setting. (4) Lists/grids stagger in on first mount only (FadeInDown, 30 ms, max 8 items) with LinearTransition on add/remove. (5) Waits over ~300 ms (icon rendering, profile generation, exports) show a shimmer skeleton or progress in the final layout rather than a bare spinner; toasts spring in/out. (6) Tabular figures, consistent elevation tokens, expo-blur glass only where contrast stays WCAG AA, splash fades into the first screen after fonts load, designed empty states. (7) Guardrails: Expo Go libraries only (reanimated, gesture-handler, expo-haptics, expo-blur, expo-linear-gradient, react-native-svg); no new native modules; animate transform/opacity on the UI thread; idle animation paused when unfocused/backgrounded; no core-logic changes; tests green; say "premium polish" in the finish message; never claim real-device testing.

Glaze-specific: G1 Theme gallery: scroll-driven parallax on theme cards (slight scale/translate of the artwork as the card crosses the centre) and the mini Home Screen icons pop in staggered when a card settles. G2 Shape picker: changing shape morphs every preview icon's mask with the spring (animated corner radius / interpolated SVG path), selection haptic, selected shape ring slides between options. G3 Apply flow: icons ripple into the mock Home Screen one by one, then a success haptic and a short glaze-drip gradient sheen sweeps across the "Install icons" CTA. G4 Personal photo background: pinch/pan crop with momentum and rubber-band edges, live preview behind the themed icons. G5 Live tab / animated wallpaper: loop preview inside a phone frame with a mock Lock Screen clock over it and a faint glass reflection; trim handles press-scale with selection haptics. G6 Theme detail: Home and Lock mocks cross-fade when toggled; the header tints to the theme's palette with a soft fade.
