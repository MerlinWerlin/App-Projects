# Native photo albums

The Widget Studio photo album supports small, medium and large Home Screen widgets in native capability version **4**. The editor payload remains version 2. Existing builds keep the draft and require a native update before applying albums. Expo Go and Android keep a local preview.

The system picker selects up to twelve still images without requesting broad Photos access. Glaze keeps private document copies using bare filenames, so saved drafts survive an app-container path change. Private filenames and file URLs never enter `widgets.json`. Before saving, every album draft for the theme is imported into the App Group. A failed image import prevents the manifest from being published.

`AlbumPhotoImport.swift` uses ImageIO to create an orientation-correct thumbnail before decoding an original at full size. Each shared JPEG has a maximum long edge of 1,200 pixels and a two MiB byte limit. Re-encoding strips source metadata; a content hash deduplicates shared copies. Only importer-owned `album-<40 hex>.jpg` names are accepted. Manifest validation rejects missing files and path traversal. A successful manifest commit reclaims unreferenced shared JPEGs older than seven days. Private copies removed from saved drafts are deleted only after the new draft is persisted and no other theme or size references them.

`PhotoAlbumProvider` issues the current entry and twelve future entries, each containing a filename rather than a decoded image. Rotation supports 15/30/60/180/360/720/1440-minute intervals. Intervals use epoch-aligned boundaries and a persisted manual offset. Actual display timing is controlled by [WidgetKit](https://developer.apple.com/documentation/widgetkit/keeping-a-widget-up-to-date), so the selected interval is a schedule, not a real-time timer guarantee.

The native view reads the same saved regions as the app preview. Captions sit on an 86% black scrim with white text, and medium/large designs reserve a 44 pt Next control. Next uses an AppIntent without opening Glaze. Each size's design and photo selection has its own coordinated, atomic cursor file. Empty or unreadable photos show a localized prompt on the theme background. A background tap opens the Widgets tab. All installed instances of the same kind and size share that size's saved album.

Validation sources are `scripts/prepare-native-album-review.mjs`, `scripts/native-album-review.swift` and `.github/workflows/glaze-native-album.yml`. Fixtures use the actual editor serializer and six existing native palettes. Eleven fresh language launches cover import bounds, repeat import deduplication, missing images, metadata, reference validation, rotation boundaries, cursor persistence, cleanup ownership and three-size rendering. Exact-source run results are recorded in the local release-simulation receipts; implementation alone is not a passing runtime result. Picker UI and installed album Next have separate runtime checks; system tint, memory measurements and physical-device behavior need their own execution.

For a real signed iPhone build, use the `production-native` EAS profile (or native-enabled development/preview profile). The plain `production` profile currently sets `GLAZE_NATIVE=0`. `scripts/verify-signed-widget-groups.py` reads an existing Apple-signed `.app` or `.ipa` on macOS and verifies both signatures, bundle identities, matching real teams, unexpired provisioning profiles and Group authorization. It does not build, upload or qualify runtime sync. CI's `GLAZETEST0` simulator entitlements are explicitly rejected by that preflight.
