# Glaze audit + feasibility — answering the owner review of 12 Oct 2026

Review: `docs/feedback/2026-10-12-owner-review.md` (stages 1–2: audit + feasibility). Inspected in the code on 12 Oct 2026 (run 5). Nothing here has been tested on a real iPhone; the trial has only run through core unit tests and a code walk-through in the cloud.

## iOS limits that shape every answer

| Question | What iOS allows | What Glaze does |
|---|---|---|
| Discover installed apps | An ordinary iOS app **cannot list installed apps**. `canOpenURL` only answers for schemes declared in the app's Info.plist (max 50) and doesn't work in Expo Go. | Curated searchable catalogue (253 apps today) + manual **"Add an app"** (name + URL scheme). |
| Replace an app icon | **Not possible.** Web clips (configuration profile) and Shortcuts **add** a new icon that opens the real app; the original moves to the App Library. | Say so in onboarding, tips and the install flow (already in the "icons are added, not replaced" tip). |
| Icon shape | Glaze bakes the shape into the PNG it generates (`src/core/shapes.ts` → `IconCanvas`), but **iOS draws its own rounded-square mask over every web clip / Shortcut icon**. Circle/blob shapes show as artwork inside that mask, on the theme or wallpaper colour behind them. | Shape picker with previews plus a **"How it looks on iPhone"** toggle that overlays the iOS mask, so the preview never promises a true circle. |
| Set a wallpaper | **A normal app cannot set any wallpaper.** | Save to Photos at device resolution, then step-by-step: Settings › Wallpaper › Add New Wallpaper › Photos. |
| Animated lock screen | iOS wallpapers don't play GIFs or videos. A **Live Photo** wallpaper animates only on long-press/wake (and not on every iOS version or setting). A truly looping lock screen needs the **iOS 26 Now Playing animated-artwork** path (T10). | T10 module (dev build only, iOS 26+). T11 Live Photo export (dev build). In Expo Go: full editor + preview + clear "needs the full build" sheet; TRIAL2 adds saving the framed source and a still frame to Photos so something usable comes out of Expo Go. |
| Photo library | Read via the system picker (no permission needed for picking); saving needs add-only permission. | expo-image-picker (pick) + expo-media-library (save). Copies stay in the app's documents folder; nothing leaves the phone. |
| Custom per-app images | Allowed: the user's own images, stored locally. Brand logos never ship in Glaze. | Per app **and theme** override images (TRIAL2). |
| Cost | — | No servers, no paid APIs, no AI calls inside Glaze. External image tools are the user's choice. |

**Exact icon image specs (from the code, used in the external-AI prompt):** profile (bulk install) icons are rendered as **180 × 180 px PNG** (`PROFILE_ICON_SIZE`, `src/core/install.ts`); icons saved to Photos for the Shortcuts method are **360 × 360 px PNG** (`PHOTO_ICON_SIZE`). An uploaded override image is drawn into the icon's shape and captured at those sizes, so a **square image of at least 360 × 360 px** (PNG or JPEG) is enough; larger is fine. Keep important artwork inside the **central ~70 %** of the square: a circle mask keeps only the inscribed circle (its inscribed square is 70.7 % of the side), and iOS rounds the corners again.

## The 9 review areas

### 1. Theme redesign — **partial (looks are palette swaps)**
- Exists and works: 12 starter themes (`src/core/themes.ts`) + 27 Plus themes in 3 packs (`src/core/plusThemes.ts`), each a palette, an `IconStyle` (shape, solid/gradient/glass background, glyph colour/set) and generated wallpaper params (`gradient | mesh | grain | pattern` with `dots | grid | waves | checker`).
- What's wrong: the owner is right. Every theme is the same structure with different colours: no illustrations, frames, stickers, textures or type. Icons are a Feather/in-house glyph on a coloured shape.
- Missing: an artwork layer. **Plan (T24):** an original SVG motif library in `src/core/artwork.ts` (strawberries, cream swirls, daisies, leaves, mushrooms, moons, stars, planets, clouds, hearts, bows, lace, ribbons, sparkles, waves…), each theme declaring an icon **frame** (scalloped, lace, stitched, ribbon), **corner stickers**, a **texture** (gingham, paper, linen, starfield, watercolour wash) and a wallpaper **composition** (scattered motifs, border garland, sky scene, tiled picnic). At least 14 genuinely distinct free themes: Strawberry Dessert, Cottage Garden, Wildflower Meadow, Celestial Night, Moon Phase, Whimsy Forest (mushrooms), Romantic Lace, Cloud Nine, Seaside Shells, Retro Diner, Matcha Café, Cherry Blossom, Pumpkin Patch, Candy Arcade. No characters or brands (e.g. "strawberry dessert", never a licensed character). Existing ids stay valid (old themes map to their nearest new look) so saved state survives.

### 2. Own photo background in every theme — **missing**
- Exists: wallpaper maker (`app/wallpaper.tsx`, `src/core/wallpaper.ts`) generates gradient/mesh/grain/pattern at the device's exact resolution (`DEVICES` in `src/core/loop.ts`, e.g. 1179 × 2556) and saves it to Photos (`src/render/saveWallpaper.ts`). The Studio stores an average `wallpaperColour` for icon backdrops.
- Missing: no photo source at all. **Plan (T25):** wallpaper source = theme artwork | **my photo** in every theme; pick from Photos, pan/pinch-scale/crop to the device aspect (crop maths in `src/core`, tested), optional theme overlay (motif border, tint, grain) on top of the photo, local copy keyed by theme, preview with the themed icons in `HomeMock`/`LockMock`, save to Photos at device size, reset to theme artwork.

### 3. Icon shape picker in the Themes tab — **partial**
- Exists: 4 shapes (`squircle`, `circle`, `rounded`, `blob`; `src/core/shapes.ts`), chosen per set in the Icon Studio as a segmented text control; baked into the exported PNG.
- Missing: no shape choice in the Themes tab, no visual comparison, no honest iPhone-mask preview, and no plain **square**.
- **Plan (T26):** visual shape row (theme artwork inside each shape) in the Themes tab and theme detail, selected state obvious, change any time; add `square`; "How it looks on iPhone" toggle overlays the iOS rounded-square mask; the chosen shape is what gets baked into the exported icons.

### 4. Override existing icons — **partial**
- Exists: `IconOverrideSheet` lets the user pick their own photo for any selected app (copied into the app's documents folder), change glyph/colour/label, and "Reset". Works for catalogue and custom apps.
- Gaps: overrides are keyed **by app only**, so the same image follows every theme; reset deletes the image (it isn't kept for reuse); nothing shows which icons are customised; no entry point from the Themes tab.
- **Plan (T27):** overrides keyed by **app + theme** (with an explicit "use in all themes"), a local custom-image library so an uploaded image is kept and can be re-applied, restore-to-theme-artwork that keeps the image, a "customised" badge on icons, and an Override Icon entry in the Themes tab. Migration keeps today's per-app overrides as the user's current theme's overrides.

### 5. Unsupported apps — **partial**
- Exists: the catalogue's apps without a URL scheme are routed to the Shortcuts method; "Add an app" (name + optional URL scheme) creates a custom app.
- Missing: no guided workflow, no prompt template, no clear "unsupported" marking.
- **Plan (T28):** "Missing an app?" flow: search → not found → add it (name + scheme help) → **copyable prompt template** for ChatGPT or any image tool (fills in app name, theme name, palette hex values, motif words and the real specs above) with instructions to attach a screenshot of the original icon and a theme example image (Glaze can save a theme sample card to Photos for this) → upload → saved for that app + theme. Glaze makes no AI or network calls.

### 6. Master app-icon collection — **partial**
- Exists: `src/core/catalogue.ts`, 253 apps with id, name, category, URL scheme (46 verified), glyph and search aliases; the Studio's "My apps" category holds custom apps.
- Missing: clear supported/unsupported status, coverage across categories the owner listed (games are thin), and one data model tying app ids, theme ids, icon assets and user overrides.
- **Plan (T28):** extend to ~350 popular apps (social/messaging, streaming, games, productivity/education, utilities), add a `support` status (`scheme verified | scheme unverified | shortcuts only`), and an `iconFor(appId, themeId, overrides)` resolver that returns theme artwork, the user's override, or "needs your icon". Matching icons across every theme come from the theme artwork (glyph + frame + stickers), never brand logos.

### 7. Themes tab as the central place — **partial**
- Exists: theme gallery with mock Home Screen cards, detail page (Home + Lock mocks, Apply flow: wallpaper → apps → install), tip cards.
- Missing: shape, photo background, overrides and unsupported-app entry are spread across the Icons tab and Wallpaper screen; no "customised vs theme artwork" view.
- **Plan (T26/T27/T28 + T31):** the Themes tab gets a "Your look" panel: background (theme art | my photo), shape row, icon grid with customised badges and restore, "Missing an app?" entry and the preview-vs-iPhone toggle. The Icons tab stays as the detailed studio.

### 8. Tips — **exists, partly hidden**
- Exists (T09): 3 first-run tip cards on the Themes tab (`icons-added`, `bulk-install`, `live-lock`), dismissible one by one or all at once, stored in AsyncStorage (`glaze.tips.v1`), and **Settings › "Show tips again"** already resets them. They weren't removed; after "Dismiss all" they simply never come back unless the user finds that Settings row.
- **Plan (T29):** keep the store and the existing 3 tips (and their dismissed state); add a **Tips** library screen (always reachable from Settings and a "?" on the Themes tab), contextual one-line tips near features (photo background, shapes + iPhone mask, overrides, missing apps, wallpapers, live loops, profile "Not Verified"), and a "Show tips again" control on the Themes tab too.

### 9. Animated lock screen wallpaper — **exists, buried**
- Exists (T08/T10/T11): Live tab: pick a **video or GIF** (GIFs kept animated), trim ≤ 15 s, crop to the device's screen aspect, speed, playlist, preview; "Set on Lock Screen" uses the iOS 26 module in a dev build or explains it needs the full build; "Save as Live Photo" (dev build) with set-as-wallpaper steps.
- Missing in Expo Go: nothing can be saved, so the trial can't produce a wallpaper from a GIF. Not prominent: a tab labelled "Live" with no hero entry on Themes.
- **Plan (T30):** a hero card on the Themes tab ("Make a moving lock screen"), the tab renamed "Live Lock" with a clearer icon, save-to-Photos for what Expo Go can produce (the framed source video/GIF copy and a still-frame wallpaper), and step-by-step apply instructions per iOS version (iOS 26 full build: real loop; iOS 16–25: Live Photo plays on long-press; Expo Go: still frame + what the full build adds).

### New requirement B: in-app feedback email — **missing**
- **Plan (T23, ships first):** Settings row + small Themes entry + "Report a problem" in error states; expo-mail-composer (Expo Go-compatible, no server); subject always starts "Glaze feedback – <type>"; machine-readable footer; optional screenshot; fallback with copyable address/message + mailto; address in `src/config/feedback.ts`; "Data Not Collected" stays true.
