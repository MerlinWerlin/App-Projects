# Shadowlight Meadow

A California quail, desert cottontail, California poppy, fence lizard and two meadow mushrooms cast three broad colored shadows. The main figures keep their natural colors. Each shadow begins where the subject meets the ground and spreads away in muted teal, rose or ochre.

The coordinator kept the exact quail after reviewing full, 170 and 85 px comparisons. That quail is the only style reference for the original companion works and the meadow wallpaper. One narrowly focused own-source edit removed an extra foot from the lizard while retaining the head, tail, four natural limbs and all three shadow directions. The initial unselected lizard and exact edit reference are retained.

The five transparent artworks are separate. A warm stone field lets the whole shadows breathe in Artwork, and a naturally curved grass seedhead fits the compact live corners. The nine preview layouts use the app's supplied clock, battery and calendar types. The continuous meadow wallpaper uses the quail as the main subject and preserves the four companion groups.
