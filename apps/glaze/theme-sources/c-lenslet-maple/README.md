# Lensleaf Glade

A whole autumn maple leaf, red fox, wren, acorn and comma butterfly carry broad flat views of one copper-and-spruce woodland. In each cutout, the cream mushroom moves against the distant trunk, with slight changes to the overlap. The artwork borrows this visual idea from integral imaging.

The five artworks are separate transparent images. The coordinator reviewed the maple at 170 and 85 px and kept the exact first artwork. The four companions reuse that image as the only style reference. Every source remains intact inside its 1024-square Artwork canvas.

The woodland wallpaper uses only the exact maple as a reference. The leaf carries the strongest views, with the wren, butterfly, fox and acorn illustrated naturally in the forest. The calm upper spruce field leaves space for the phone clock.

A small outline of a maple leaf and one vein accompany compact live values. Larger fields use the whole leaf or a simple view of the grove. The pack supplies the existing live clock, battery and calendar sizes. See the QA folder for the source, encoded artwork, wallpaper and live preview checks.
