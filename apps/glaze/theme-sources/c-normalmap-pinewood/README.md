# Facetlight Pinewood

A pine cone, woodpecker, squirrel, shelf fungi and columbine use four broad colors to describe the direction of a surface. Periwinkle faces, cyan left sides, rose right sides and mint upper lips recur at the contours that define each subject. The artwork draws on the appearance of surface direction images.

The five Artwork pieces are separate images. The coordinator accepted the first pine cone unchanged after comparing it with existing art at 170 and 85 px. The other four used that image as a style reference. The source folder preserves each selected original and its exact prompt. The whole artwork fits proportionally within 900 px on a 1024-square transparent canvas.

The wallpaper gathers the five forms on a slate field. A layout edit curved the columbine stalk down to the ground between the cone and squirrel and added quiet tree contours behind the left subjects. The original wallpaper and complete reference history are retained.

The Artwork corners use a quiet slate field. A plain pine sprig fits compact live headers. The clock and battery use a larger cone and a simplified scale motif, and the live calendar uses the supported folio layout. See the QA folder for the local pack and visual checks. Canonical integration and on-device verification remain with the coordinator.
