# Glaze

Lock screen, icon theme and widget app (Expo / React Native, iOS + Android).

**To try it:** download the newest trial kit from the Glaze Build page and follow
[docs/TRIAL.md](docs/TRIAL.md). Use the downloaded kit, not an older copy on the PC:
`START_TRIAL.cmd` prints "Built from commit: ..." first (see `KIT_VERSION.txt`), and that code
must match the "Trial kit: commit ..." line on the build page.

Build process and rules: `ops/WORKFLOW.md`, `ops/CONVENTIONS.md`, `docs/PLAN.md`.
