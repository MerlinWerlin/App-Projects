# Native config pieces

One JSON file per native feature, merged by app.config.ts only when GLAZE_NATIVE=1 (dev/production builds). Expo Go never reads these.
Shared ids: App Group `group.com.jared797.glaze` (theme JSON for widgets), bundle id + Android package com.jared797.glaze.
queryschemes.json (T229) is generated by scripts/gen-query-schemes.mjs from src/core/installedProbe.ts: LSApplicationQueriesSchemes for the installed-apps check (<= 50 schemes, Apple limit).
datawidgets.json (owner-1102b T280/T281): calendar (full access + legacy key) and When-In-Use location usage strings for the Next event and Weather widgets. Asked only from app/widget-access.tsx, which those widgets open when tapped.
