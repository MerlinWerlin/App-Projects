# Store listing

Moved for 1.0.0 (15 Nov 2026): the paste-ready App Store copy, the other App Store Connect fields and the App Review
notes are in `store/LISTING.md`. `node tools/store/limits.mjs` checks it (and `npm test` runs the same checks).

A Google Play listing is not written yet; write it from `store/LISTING.md` when an Android build is planned.
