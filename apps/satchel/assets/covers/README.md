# Trip cover art (T152)

Bundled illustrated covers go here as `<scene>-<day|night>.webp` (for example `mountains-night.webp`), 800 x 450,
all together under 1.5 MB. Each file is listed in `src/content/coverArt.ts`; a scene with no file keeps its SVG
drawing. Prompts, style and import steps: `docs/research/COVER_ART_REQUEST.md`.
