# Satchel mascot art

An original character made for Satchel: a tan leather satchel with a strap handle, a brass-buckled front pocket,
pie-cut eyes, rosy freckled cheeks, black rubber-hose arms and legs, white four-fingered gloves and round brown
shoes, hand-painted in a 1930s rubber-hose watercolour-and-ink style. It is not based on any existing cartoon or
game character.

Generated 16 Nov 2026 with Nano Banana Pro in Google Flow (Jared's account), all six poses from one reference image
so the character stays consistent. The white page was removed with a flood fill from the edges plus a pass that
clears enclosed bare-paper gaps (under the strap, between an arm and the body) while keeping the painted gloves,
eye whites and cast; each image is trimmed, padded square and saved as a 512 px transparent PNG.
