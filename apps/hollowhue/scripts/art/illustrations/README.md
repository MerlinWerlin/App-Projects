# Original Hollowhue illustration sources

These 42 lossless WebP files preserve the selected artwork created with built-in image generation for
the Hollowhue phase 2 artwork revision on 4 November 2026. The importer reads them to build closed colour
regions and smooth vector ink for the app. Names, subjects and generation prompts are recorded one level
up in `illustrations.json` and `generation-prompts.json`. These source files are not runtime downloads;
the baked, compressed vector catalogue is committed under `src/scenes/art`.
