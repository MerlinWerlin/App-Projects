# Hollowhue gallery covers

These generated PNGs let blank gallery cards show the new illustrations without creating thousands of
editable SVG paths during app launch. Cards with paint or drawing on their opening picture still use the
live vector preview. The canvas always uses editable vectors. Rebuild with `scripts/import-illustrated-art.py`;
the original illustration sources and prompts are preserved in `scripts/art` for the Hollowhue artwork revision.
