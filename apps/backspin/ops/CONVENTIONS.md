# Backspin code rules
- `src/core` is pure TypeScript (no React Native imports) and has node --test tests; imports carry `.ts`.
- Only `src/native/*` imports Expo native modules; anything not in Expo Go (expo-iap) is a guarded require.
- Every UI string goes in `src/i18n/en.ts`; translations in `src/i18n/locales` (StarNet Luna), checked by i18n.test.ts.
- Content (lines, verdicts) is generated by StarNet Luna through the advice bridge (requests and raw answers in the PC folder `ops/luna`), screened by a GUARD pass and Claude. Never add copyrighted lyrics, brand or celebrity names.
- Checks: `npm test`, `npx tsc --noEmit`, `npx expo export --platform ios` (TSC_REPORT.cmd runs all three on the PC).
- PC-only files: RUN.cmd, SETUP_SDK57.cmd, TSC_REPORT.cmd, BUILD_VERSION.txt. Port 8097.
