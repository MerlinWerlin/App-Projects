# Reply to App Review: Guideline 5.6 (Backspin 1.0, submission 22938d32)

Paste the text below into the App Review reply in App Store Connect when resubmitting with version 1.0.1.

---

Hello,

Thank you for reviewing Backspin. Nothing in the app is hidden, and no features are switched on or off after review. Every screen can be reached from the tabs on first launch, with no account or login.

- Pricing is shown up front. The first 10 goes are free with every feature on. The goes left are shown on the Play tab. After that, new rounds need Backspin Plus, a one-time lifetime unlock. Restore Purchase is on the same screen (Play tab > free goes badge, or Settings > Backspin Plus). Saved takes still play without it.
- Audio stays on the device. Recording only happens while the player holds (or taps) the record button. Reversing and scoring run on the phone, and recordings are never uploaded.
- Version 1.0.1 removes remote code updates. Build 7 included a library (Expo Updates) that could download new app code after release. We have removed it completely. The 1.0.1 binary cannot download or run code that is not in the reviewed build, so the build you review is exactly what users get. The app no longer connects to any server apart from Apple's In-App Purchase, and App Privacy is now "Data Not Collected".
- The app works the same on iPhone and iPad. On iPad, 1.0.1 keeps the content in a centred column so it reads well in any orientation.

If any screen or behaviour looks unclear, please tell us which one and we will explain or change it.

Thank you,
Jared Bradley
