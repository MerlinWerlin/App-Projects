# Google Play preparation tools

This source folder belongs to the App-Projects Android preparation branch and the APPS Google Play stage in the master roadmap. `node --test scripts/play/variants.test.cjs` checks package isolation and configuration regressions for the seven self-contained app overlays. Per-app draft listings are in `apps/<app>/store/play-listing.json`; technical release requirements and artifact evidence are in `docs/GOOGLE_PLAY.md`.

The manual `Android test APK` GitHub workflow compiles an embedded release-mode APK signed with Expo's generated test key. `verify_apk.py` checks the actual package, target SDK, embedded JS and each native ELF's load alignment; Android tools verify its signature and 16 KB ZIP alignment. `smoke-apk.sh` installs and launches the artifact on a disposable API 35 emulator and captures logs, UI XML and a screenshot. `rowlight-smoke.py` exercises sample-project creation, row increments and persistence after force-stop. Backspin also runs native AAC-decoding instrumentation tests with a generated test tone. These checks do not verify Play Billing, production signing, a 16 KB runtime or all device features.

Run with `gh workflow run play-apk.yml --ref codex/google-play-prep -f app=crochet -f smoke=true`. To test an already compiled APK after a test-runner repair, add `-f artifactRun=<build-run-id>`; the APK and its source commit remain unchanged. Each download contains `verification.json`, the build's source commit, signature and manifest evidence. Local downloads live in ignored `apk-output/`, never in release source or git. No submission or paid EAS build is performed.
